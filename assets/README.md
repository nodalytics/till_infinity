# Mark

Generated by `generate.py`. Do not hand-edit anything in `svg/`, `png/` or
`favicon/`; change the geometry there and re-run:

```bash
python3 generate.py --fonts /path/to/dir/with/PlexSans-500.ttf
```

## The idea

**Two unequal circles, tangent at a single point.**

The load-bearing idea in this project is that a level is where volatility
turns, not where price poked: the leg in and the leg out meet at an origin, and
the wick beyond it is the zone's width rather than its position.

So the mark is drawn from the turn, not from the name. Two turns of unequal
width meet at one origin, which is the tangency. A lemniscate's defining
feature is its crossing point, so the infinity association survives without
anyone having drawn an infinity symbol: the topology is there, the cliche is
not.

**The asymmetry is the whole point.** Equal circles would be a figure eight,
which is a symbol for the name. Unequal circles are a statement about the
subject, and they are what makes the shape memorable at a glance.

## What the previous mark did that this one does not

| Old | Why it was replaced |
| --- | --- |
| An infinity loop **and** a rising tail | It spelled the name twice and said nothing about what the system does |
| The tail broke out to a new high | A returns claim, which is the one thing a mark must never make |
| A teal-to-gold gradient | Died in one colour; a mark has to work in a single ink |
| A 12px stroke at 230x128 | Blurred into a blob at favicon size |

## Two optical sizes

The full mark uses a 2.5 stroke on the wide turn. **At or below 20px that
stroke is under a pixel**, so the small variant thickens it to 3.4 and closes
the ratio from 13:7 to 12.5:7.5, keeping both turns legible. The PNG and
favicon builds switch automatically at the cutoff.

## Backgrounds: never ship one colour

A single-colour mark cannot survive an unknown background, and this is not a
matter of taste. Measured against the two grounds that matter:

| Colour | vs white | vs a dark canvas | Verdict |
| --- | --- | --- | --- |
| `#14181A` ink | 17.87:1 | **1.06:1** | invisible on dark |
| `#E7EAE6` paper | **1.21:1** | 15.60:1 | invisible on light |
| `#2E8B72` **theme-safe** | 4.16:1 | 4.55:1 | **works on both** |

The theme-safe verdigris is deliberately not neutral grey. Grey clears the
contrast bar too, but it spends the one colour the mark gets on nothing; this
stays in the brand family and reads as a decision rather than a hedge.

Three files are generated for the repository README, and it uses `<picture>`
so each ground gets the crisp version and anything that will not switch still
gets a legible mark:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/logo-dark.svg">
  <source media="(prefers-color-scheme: light)" srcset="docs/logo-light.svg">
  <img src="docs/logo.svg" alt="Till Infinity" width="92">
</picture>
```

`docs/logo.svg` is the theme-safe one, so it is the right fallback for npm,
other Markdown renderers, and anywhere the background is not knowable.

**In HTML and JSX, prefer `svg/mark.svg`.** It uses `currentColor` and inherits
from CSS, which solves this properly. The three-file arrangement exists only
because an `<img>` cannot inherit colour.

## Rules

- Monochrome by construction. It must work in one ink.
- **Never equalise the circles.** The asymmetry is the idea.
- Never add a tail, an arrow, or a rising line. The mark states a mechanism,
  not an outcome.
- No gradients, no glows, no container tile.
- Clear space: one radius of the wide turn on all sides.
- App icons ship on an opaque ground. A transparent iOS icon reads as a hole.

## Relationship to Nodalytics

The palette and the lockup proportions are the Nodalytics ones, and the
unequal-weight logic is deliberately the same as the Nodalytics weighted
lattice. That is family resemblance rather than copying: if this repository is
reframed as **Nodalytics Research** output, the mark already sits inside the
system. See `brand/docs/07-naming.md` and `brand/docs/08-visual-identity.md`.
